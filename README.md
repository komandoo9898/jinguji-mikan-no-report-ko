# 탐정 진구지 사부로 미완의 르포 — 한글 패치 (PS1, 보급판)

PS1 일본판 『探偵 神宮寺三郎 未完のルポ』(보급판, SLPS-03016)을 한국어로 옮기는 비공식 팬 패치입니다.
게임 디스크 이미지는 포함하지 않습니다. 본인이 가진 디스크에서 만든 이미지에 적용하세요.

## 한글화 범위
- 장면 대사 전부(313장면, 약 3만 행)
- 소지품 이름·설명
- 수사 메모 4종(진구지·쿠마노·요코·요노), 엔딩 메시지·크레딧
- 명령 버튼, 저장 메뉴, 이름표, 타이틀 메뉴·로고, 주의 문구 그림
- 설정(스타트 버튼) 화면, 저장·불러오기·메모리 카드 메시지

아직 일본어인 것: 로딩 화면 로고, 메모 화면 아래 조작 안내 그림, 추리 도해·배경 간판 그림, 동영상.

## 적용 방법
1. 원본 이미지를 BIN/CUE(트랙 2개, BIN 1개)로 준비합니다. CHD라면 `chdman extractcd -i 원본.chd -o mikan.cue -ob mikan.bin`.
2. 원본 BIN이 아래 해시와 같은지 확인합니다.
   - 크기 467,986,848 바이트
   - SHA-1 `7e80c63dac70f08ca2bdc2a43f509b08fd3c8341`
   - MD5 `c7c270f9bf9619136b3b31a0fb0ae60a`
   - CUE: `TRACK 01 MODE2/2352` / `TRACK 02 AUDIO` (INDEX 00 39:45:57, INDEX 01 39:47:57)
3. PPF 패치를 적용합니다(원본은 백업해 두세요).
   - PPF-O-Matic 등 PPF 3.0 도구, 또는 동봉한 파이썬 적용기:
     `python apply_ppf.py mikan.bin jinguji_mikan_ko.ppf mikan_ko.bin`
   - ePSXe는 PPF를 직접 불러올 수도 있습니다.
4. 결과 BIN 이름에 맞춰 CUE의 `FILE "..."` 줄을 고친 뒤 에뮬레이터에서 CUE를 엽니다.
   - 적용 후 SHA-1은 `checksums.txt` 참고.

## 알려진 점
- 띄어쓰기가 넓게 보입니다(공백도 글자 한 칸 폭).
- 한글 글자는 Windows 굴림 내장 비트맵을 바탕으로 했습니다.
- 실기 확인은 에뮬레이터(ePSXe) 위주입니다. 버그 제보 환영합니다.
